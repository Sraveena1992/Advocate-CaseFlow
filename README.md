## ✨ Key Features

### 👨‍⚖️ Advocate Portal
- **Secure Login** - Advocate ID: `7500000088`
- **Add New Case** - Auto Client Mobile Login ID Generation
- **Court & Case Type** - High Court, District, Supreme, Property, Criminal etc.
- **Payment Tracking** - Total ₹25,000 | Advance ₹10,000 | Pending ₹15,000 Auto-Calculate
- **Workflow Locked** - `NEW → PROGRESS → REVIEW → WON/LOST (Final)` - Reverse movement restricted
- **Revenue Stats** - Total Revenue, Pending, Cases Overview
- **Timeline** - Every stage with timestamp

### 👤 Client Portal (Professional Login)
- **Login** - Advocate ID + Client Mobile Number
- **View My Case** - Status, Court, Next Hearing Date
- **Payment Transparency** - Total / Paid / Pending Amount
- **No Edit Access** - Client can only view, not modify

### 💬 CometChat MCP Integration
- Integrated via **CometChat MCP Server**
- VS Code + CometChat Connector for real-time messaging setup
- Ready for Advocate-Client secure chat

## 📸 Workflow
example:

1. Advocate Login (7500000088)
2. Add New Case → Client Name, Mobile, Court, Type, Fees
3. Payment Entry → Total, Advance, Mode (Cash/UPI), Next Date
4. Timeline Auto-Created → NEW • 10/14/2026, 12:11 PM
5. Move to Next Stage → Progress → Review → Won/Lost
6. Client Login → Advocate ID + Mobile → View Case & Payments
